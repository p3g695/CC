# CC - 3D Animation Studio 🎬

![Version](https://img.shields.io/badge/version-0.1.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

**CC** is a lightweight, web-based 3D animation software designed to make object positioning, scene layout, and timeline animation intuitive and accessible right inside the browser.

---

## 🌟 Key Features

* **Interactive 3D Viewport:** Built on Three.js for fast real-time 3D rendering.
* **Scene Inspector & Hierarchy:** Easily view and inspect cameras, meshes, and light sources in your scene.
* **Animation Timeline:** Scrub through frames, play/pause playback, and manipulate keyframe controls seamlessly.
* **Transform Controls:** Quick access to select, move, and rotate tools in a clean workspace layout.
